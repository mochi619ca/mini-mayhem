# Mini Mayhem — screens

Captured from a headless Chrome at 390×844 (phone size) against the real server.
Regenerate with the two-phone script; each image is one player's screen.

Images are not committed: the app renders identically from source, and a stale
screenshot lying around is worse than none. To produce them, run the two-phone
script at 390x844 and capture each `[data-game]` screen.

| Screen | What it proves |
|---|---|
| `lobby` | room code, seat list, host controls, the five games in order |
| `reaction` | grey → green transition, one tap, "154 ms" feedback |
| `targets` | board with fading targets, live hit counter |
| `memory` | square 3×3 grid, flash replay, round pips |
| `stop` | centre marker, banded zones, three attempt pips |
| `stroop` | colour word in a conflicting ink, four colour buttons |
| `result` | per-game finish order with points, running standings |
| `finale` | podium, champion, full match standings |
